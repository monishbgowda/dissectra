# Dissectra - User Guide

## Overview

Dissectra is an AI-powered 3D anatomy analysis application for Android. Capture images of objects, analyze them with AI, and generate interactive 3D models for exploration.

## Features

### 📷 Smart Scanning
- **Camera Capture**: Take photos directly within the app
- **Gallery Import**: Select images from your device's gallery
- **Image Validation**: Automatic size and quality checks
- **Tips & Guidance**: Built-in tips for best scan results

### 🧠 AI Analysis
- **Object Recognition**: Advanced AI identifies scanned objects
- **Label Detection**: Extracts relevant labels and metadata
- **Confidence Scoring**: Shows analysis reliability
- **Offline Storage**: Saves scans locally on your device

### 🎨 3D Model Viewer
- **Interactive Models**: View generated 3D models
- **Model Management**: Access your scan history
- **Status Tracking**: Monitor processing status
- **Future Enhancement**: Full 3D rendering coming soon

### 📊 Scan History
- **Search Functionality**: Find scans by name or labels
- **Status Filters**: Filter by Complete, Processing, or Failed
- **Detailed View**: View scan details and metadata
- **Quick Actions**: Easily re-access previous scans

### ⚙️ Settings
- **Appearance**: Dark mode enabled by default
- **Storage Management**: Clear cache and manage downloads
- **About**: Version information and app details
- **Feedback**: Rate the app and send feedback

## Getting Started

### Installation

1. Download the Dissectra APK file
2. Enable "Install from Unknown Sources" in your device settings
3. Tap the APK file to install
4. Grant necessary permissions (Camera, Storage)

### First Launch

When you first launch Dissectra:
- You'll see the **Home** screen with feature cards
- Tap **"Scan Object"** to capture your first image
- Or tap **"View History"** to browse your scan history

## How to Use

### Scanning an Object

1. **Navigate to Scan Tab**
   - Tap the "Scan" tab in the bottom navigation

2. **Capture or Select Image**
   - Tap **"📷 Camera"** to take a new photo
   - Or tap **"🖼️ Gallery"** to select from your gallery

3. **Review Your Image**
   - Preview the selected image
   - Check file size and name
   - Tap the **✕** button to clear and reselect

4. **Start Analysis**
   - Tap **"Analyze & Generate 3D"**
   - Wait for processing to complete
   - The app will automatically navigate to the Viewer

### Viewing 3D Models

1. **Navigate to Home Tab**
   - Tap the "Viewer" tab in the bottom navigation

2. **View Current Model**
   - If a model is loaded, you'll see the 3D viewer
   - Model information and status are displayed below

3. **Load from History**
   - Tap **"View History"** feature card
   - Select any scan to view its model

### Managing Scan History

1. **Navigate to History Tab**
   - Tap the "History" tab in the bottom navigation

2. **Search Scans**
   - Use the search bar to find specific scans
   - Search by object name or labels

3. **Filter by Status**
   - Tap filter pills: All, Complete, Processing, Failed
   - View only the scans you need

4. **View Scan Details**
   - Tap any scan item to view details
   - Navigate to the Viewer for 3D model access

### Settings

1. **Navigate to Settings Tab**
   - Tap the "Settings" tab in the bottom navigation

2. **Appearance**
   - Dark mode is currently enabled
   - Theme color: Cyan Blue

3. **Storage**
   - Clear cache to free up space
   - Manage offline downloads

4. **About**
   - View app version
   - Read privacy policy
   - Review terms of service

## Tips for Best Results

### Image Quality
- **Good Lighting**: Ensure adequate lighting for clear images
- **Steady Hands**: Hold your device steady when capturing
- **Focus**: Make sure the object is in focus
- **Background**: Use a clean, contrasting background

### Object Selection
- **Single Object**: Frame one object at a time
- **Multiple Angles**: Capture objects from different perspectives
- **Center Subject**: Keep the object centered in the frame
- **Clear Details**: Ensure important features are visible

### Storage Management
- **Regular Cleanup**: Clear cache periodically
- **Delete Old Scans**: Remove scans you no longer need
- **Monitor Space**: Check available storage before large scans

## Permissions

Dissectra requires the following permissions:

- **Camera**: To capture images for analysis
- **Storage**: To save and load images and scan data
- **Internet**: For AI processing (when online features are enabled)

## Troubleshooting

### App Won't Install
- Ensure "Install from Unknown Sources" is enabled
- Check if you have sufficient storage space
- Verify the APK file is not corrupted

### Camera Not Working
- Grant camera permission when prompted
- Check if another app is using the camera
- Restart the app and try again

### Scan Processing Failed
- Check your internet connection
- Ensure the image is clear and well-lit
- Try with a different image
- The scan will be saved locally for retry

### 3D Model Not Loading
- 3D rendering is coming soon in future updates
- Current version shows model placeholders
- Your scan data is saved and will work when 3D is enabled

### App Crashes
- Restart the app
- Clear cache in Settings
- Check for available app updates
- Report the issue via Settings > Send Feedback
